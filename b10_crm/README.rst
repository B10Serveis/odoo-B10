Usage
=====

Per fer servir el mòdul:

#. Activa’l des de Apps.  
#. Navega a **CRM → Leads**.  
#. Obre o crea un Lead i trobaràs el camp **Secondary Salesperson**:
   - Opcional; pots deixar-lo buit.  
   - No pot coincidir amb **Salesperson**.
