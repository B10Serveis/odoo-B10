Batista10 - CRM

Personalitzacions CRM per a Batista10: - Afegeix el camp Secondary Salesperson (secondary_user_id) a crm.lead. - Constraint SQL que prohibeix assignar el mateix usuari com a venedor principal i secundari.

Aquest mòdul integra i trasllada el mòdul crm_secondary_salesperson original d’Escodoo: - Original author: Marcel Savegnago (Escodoo) - Repo original: https://github.com/OCA/crm

Usage

Per fer servir el mòdul:

  1. Activa’l des de Apps.
  2. Navega a CRM → Leads.
  3. Obre o crea un Lead i trobaràs el camp Secondary Salesperson: - Opcional; pots deixar-lo buit. - No pot coincidir amb Salesperson.
