Nom original de les províncies

Versió: 1.0.3

Afegeix el camp original_name al model res.country.state i l’emplena amb els noms originals de les 50 províncies i les dues ciutats autònomes de l’Estat espanyol.

Ús

El camp es pot utilitzar en informes personalitzats i en altres mòduls. Aquest mòdul no afegeix vistes ni modifica els noms estàndard de les províncies.
