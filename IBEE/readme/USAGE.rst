A la fitxa de l'article seleccioneu el tipus d'IBEE i indiqueu els litres
per unitat de venda. Per a una llauna de 33 cl amb el tipus de 0,15 €/l,
indiqueu 0,33 litres. Reviseu els impostos de les línies de comandes i
factures ja creades.

Per imprimir el Model 520, aneu a Facturació -> Informes -> IBEE -> Model 520
i seleccioneu el període. El PDF suma les factures comptabilitzades i resta
els abonaments segons la data comptable.
