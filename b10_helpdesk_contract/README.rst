Afegeix el camp **Contracte relacionat** als tiquets de *Helpdesk*, permetent vincular un tiquet amb un contracte actiu o sense data de caducitat.

.. contents::
   :local:

Usage
=====

Per fer servir el mòdul:

1. Obre un tiquet de *Helpdesk*.
2. Selecciona el contracte relacionat al camp **Contract** (només apareixeran contractes vigents o sense data de finalització).
3. Desa el tiquet.

Known issues / Roadmap
======================

* Possibilitat futura de mostrar informació addicional del contracte vinculat dins del tiquet.
* Afegir filtres automàtics per equip o tipus de contracte.
