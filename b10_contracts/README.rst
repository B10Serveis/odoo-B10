Changelog
=========

18.0.1.0.0 (2025-08-06)
~~~~~~~~~~~~~~~~~~~~~~~
* [MIG] Adaptat a Odoo 18.  
* [ADD] Camp `contract_expiration` a `contract.contract`, computat de `date_end`.
