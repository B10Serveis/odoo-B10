When this module is active, choosing a product (by clicking on it) in the Point of Sale adds the product to the order as usual, then it immediately activates the search box again for further keyboard input.

This is tailored for POS workflows where the user makes heavy use of the keyboard to locate a product and enter an order line with a single item (or just a few), then move on to locating the next product by keyboard input.
