Usage
=====

Per fer servir el mòdul:

#. Instal·la el mòdul **b10_contacts** via Apps.  
#. Accedeix a **Contactes → Configuració → Estats**.  
#. Obre qualsevol estat espanyol i comprova el nou camp **Original Name** amb el valor carregat.
