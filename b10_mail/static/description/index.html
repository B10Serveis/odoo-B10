B10 Mail

El mòdul sobreescriu el template estàndard mail.mail_notification_layout per:

  • Mostrar únicament el logo de l’empresa (sense cap header genèric d’Odoo).
  • Eliminar tot el “Powered by Odoo” i els enllaços de “Unfollow” del footer.

Aquest petit mòdul és pensat per ser una dependència per a qualsevol altre mòdul que faci servir correus electrònics.

Usage

  1. Instal·la b10_mail_debranding com a mòdul normal.
  2. Afegeix-lo com a dependència en els manifests dels mòduls que envien emails.
  3. Reinicia el servidor i actualitza el mòdul. A partir d’ara, tots els emails basats en mail.mail_notification_layout utilitzaran el teu header i no mostraran el footer d’Odoo.
