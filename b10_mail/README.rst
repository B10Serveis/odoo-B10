El mòdul adapta la plantilla estàndard `mail.mail_notification_layout`
per:

* Mostrar només el logotip propi de l’empresa a la capçalera, quan n’hi ha.
* Eliminar el peu amb les dades de l’empresa, “Powered by Odoo” i “Unfollow”.

El cos, el seguiment i la signatura dels missatges es mantenen. Aquest petit
mòdul es pot afegir com a **dependència** dels mòduls que fan servir aquesta
plantilla de notificació.

Usage
=====

#. Instal·la **b10_mail** i configura un logotip propi a l’empresa.
#. Afegeix-lo com a dependència dels mòduls que necessitin aquesta plantilla.
#. Actualitza el mòdul després de canviar-ne el codi. Els correus basats en
   `mail.mail_notification_layout` mostraran el logotip i no inclouran el peu.
