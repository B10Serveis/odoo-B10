Usage
=====

Per utilitzar aquest mòdul:

#. Ves a **Settings → B10**.  
#. Marca el checkbox d’un mòdul per instal·lar-lo.  
#. Si el mòdul ja està instal·lat, apareixeran les opcions extra de configuració directament al panell.  
#. Desa els canvis i espera que Odoo instal·li o actualitzi els mòduls seleccionats.
