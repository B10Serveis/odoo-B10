Usage

Per utilitzar aquest mòdul:

  1. Ves a Settings → B10.
  2. Marca el checkbox d’un mòdul per instal·lar-lo.
  3. Si el mòdul ja està instal·lat, apareixeran les opcions extra de configuració directament al panell.
  4. Desa els canvis i espera que Odoo instal·li o actualitzi els mòduls seleccionats.
